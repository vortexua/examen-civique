# Prépa Examen Civique

Application d'entraînement à l'examen civique (mention naturalisation) : examens blancs de 40 questions, entraînement, fiches, cartes pour l'entretien et suivi de progression. Fonctionne hors ligne une fois ouverte (Ajouter à l'écran d'accueil sur iPhone).

Questions : liste officielle du ministère de l'Intérieur et listes CSP/CR, Livret du citoyen 2026.
